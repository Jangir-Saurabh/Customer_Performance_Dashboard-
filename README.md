🎉 I Just Completed My First Power BI Dashboard Project! 📊

I'm excited to share my first Power BI dashboard — a big step in my data analytics journey!

This interactive report uncovers valuable insights such as:
🔹 Customer demographics (age, gender, family size)
🔹 Revenue patterns across customer types
🔹 Country-wise performance (France, Australia, Global)
🔹 Loyalty score insights and top customers by revenue

💡 Skills Applied:
✔️ Data cleaning and modeling
✔️ DAX measures
✔️ Visual storytelling
✔️ KPI-focused design
